# Stream Chat Overlay

Pulls chat messages from Twitch, and displays them on-stream as an overlay using an OBS browser source, with support for Twitch/BTTV/7TV emotes, badges and GIFs.

**WARNING:** This is currently just a PROTOTYPE, and will be rewritten later as a plugin for [Streaming Toolbox](https://github.com/theodoros1234/streaming-toolbox). DO NOT USE for anything important.

Support for other streaming platforms will be posible in the future through Streaming Toolbox.
